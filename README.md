# Node.js - excluir e tela editar
Sistema completo com Express, EJS e Bootstrap.

## Rodar no VS Code
```bash
npm install
npm start
```
Depois abra http://localhost:3000

## Requisitos da atividade
- Clientes, Fornecedores e Produtos
- Excluir nas três entidades
- Tela de editar nas três entidades
- Nomes da dupla na index geral
- Bootstrap
- Deploy preparado para Render com `process.env.PORT`


Nome do projeto: projetonodejs
